# Demos

## Localizer Dashboard Demo

`localizer-dashboard-demo.webm` is an 18.4 second desktop walkthrough of the routed Localizer application.

The recording shows:

- Projects
- Project Overview
- Localizations
- Screen Discovery
- Screenshots
- App Store Metadata
- Activity
- Settings
- Create Project

The demo was recorded against the local development app at `http://localhost:3001`.

The landing page serves a copy of this recording from:

```text
public/videos/localizer-dashboard-demo.webm
```
