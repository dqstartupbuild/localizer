# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/dqstartupbuild/localizer/security/advisories/new) so project maintainers can review the report without exposing users to unnecessary risk.

Include a clear description, affected area, reproduction steps, and any suggested mitigation. Avoid attaching secrets, access tokens, or personal data.

## Scope and response

Localizer is an open-source project under active development. The maintainers will review reports when they can, but no response-time guarantee is offered. Do not rely on the project for a particular security requirement without independently assessing the code and your deployment.
